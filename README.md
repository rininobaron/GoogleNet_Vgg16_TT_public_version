# GoogleNet and VGG16 TT

This repository presents a “crazy” proposal for my final project to complete the course *Trabajo Terminal I* in the Bionic Engineering program.

The main idea is to combine two convolutional neural network architectures: the Inception-based **GoogleNet** model and the classic **VGG16** architecture, implemented using TensorFlow.

The project explores how both architectures can be coupled together in a hybrid deep learning approach.

And yes… it works!
